CSK3 data path:
- The PC removes the duplicate CFG batch.
- The PC applies 2x2 average pooling to 4 x 64 x 64 latent features.
- Each 4 x 32 x 32 feature is symmetrically quantized to 4096 int8 values.
- The per-step payload is 4096 bytes, 8x smaller than CSK2's 32768 bytes.
- The FPGA stores the reference feature in BRAM and controls all skip decisions.

Validated hardware behavior on 192.168.2.99:
- First feature establishes the reference and cannot skip.
- Identical features report similarity 1.0.
- Two consecutive skips are allowed in the hardware test.
- The next identical feature forces UNet and resets the skip streak.
- A different feature does not pass the cosine threshold.
- FPGA similarity agrees with the PC compressed-int8 reference calculation.
- Measured board-side FPGA invocation time, including ARM MMIO, was about
  0.53-0.59 ms per request.
- Measured network round trip was about 1.44-1.53 ms per request.

Notes:
- The FPGA computes dot, norms, cosine-threshold decision, warmup gating,
  consecutive-skip limiting, skip streak and reference updates.
- The PYNQ ARM only handles transport, IP control and conversion of FPGA
  statistics into the reported floating-point cosine value.
- The CSK3 protocol intentionally rejects CSK2 clients and servers.
- Deploy the bitstream, HWH and server from the same artifact set.
- The bit and HWH files must use the same base filename in one directory.
