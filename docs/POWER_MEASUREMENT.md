# 功耗与能耗实验方法（尚未实测）

软件无法从PYNQ-Z2普通SD卡容量、FPGA资源利用率或运行时间直接推算真实功耗。本文件给出可执行的测量方法，不包含伪造的测量数据。

## 测量对象

| 对象 | 推荐测量方式 | 可以说明什么 |
|---|---|---|
| PYNQ板卡整体 | 符合板卡供电规格的直流功率计串接板卡电源，连续记录电压、电流、时间 | ARM+FPGA+DDR等板卡总功耗 |
| 电脑整体 | 外接交流功率计，记录同一台电脑的任务窗口 | 电脑整体输入能量 |
| GPU遥测 | NVIDIA工具记录GPU功率（设备支持时） | GPU局部参考值，不能代替整机/板卡 |

使用合适量程、接口和供电额定值，保持原有供电方式；不在不清楚板卡电源接口时随意改线。

## 对照条件

- 对比原始20/30/50/100步、PC动态控制、PYNQ动态控制。
- 固定模型、提示词、种子、分辨率、采样器、质量评估方法和电源模式。
- 统一预热，多次交替执行，连续生成足够多张图，使短任务能被功率计采样准确覆盖。
- 同时记录空闲功率、任务开始和结束时间、生成图片数、错误及重试。
- 既报告总能量，也可另报扣除空闲后的增量能量；两个定义不可混用。

功率随时间变化时，按采样间隔对功率曲线积分得到焦耳数：

```text
energy_joules = sum((power[i] + power[i+1]) / 2 * (time[i+1] - time[i]))
joules_per_image = energy_joules / image_count
```

PYNQ方案应比较“电脑+板卡”的每图总能量。即使FPGA运算单次能量小，也可能抵不过以太网、ARM等待及板卡常开功耗。

## 记录字段

时间戳 / Timestamp、测量设备 / Meter、被测设备 / Device、方案 / Variant、提示词 / Prompt、种子 / Seed、生成张数 / Images、总耗时秒 / Seconds、平均功率瓦 / Mean watts、总能量焦耳 / Joules、每图焦耳 / Joules per image、画质指标 / Quality、重复编号 / Repeat。

没有接入上述测量工具之前，结题材料应写“功耗与每图能量未实测”，不能写“已证明节能”。
